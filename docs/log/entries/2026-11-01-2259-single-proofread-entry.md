- Scope: Phase 3 item 3.1 (review R11 and §3.5), chosen before the deferred Whisper-parameter work because it needs neither a corpus nor a device, and because "界面太复杂" was one of the two complaints that started this review. The lyric editor carried six separate proofreading buttons — 参考歌词纠正, 逐行智能纠错, 智能校对 V2, 查看逐行对比, 撤销最近更改, 恢复对齐前版本 — whose differences existed only in their tooltips; narrow layouts added five more icon buttons in the app bar and then hid four of the toolbar buttons, so the same capability lived in two places that did not agree on what to show.
