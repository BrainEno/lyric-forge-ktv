# [2026-11-01 13:54] Add a line-level lyric quality baseline tool

- Scope: Phase 0 of the recognition-quality roadmap. `tool/asr_transcript_eval.dart` scores whole-text character error rate and states in its own output that it does not evaluate timestamps or line segmentation; the reported user-visible regression (duplicated lyric rows, broken sentence boundaries, drifting timestamps) lives entirely in that gap. This adds `tool/asr_quality_report.dart`, which compares recognizer output against a hand-checked reference and reports line recall, line precision, CER on the same normalization as the existing tool, duplicate-line rate, line count ratio, and start-time MAE/median/p95 with a 500 ms tolerance rate. It also adds `--baseline` plus `--fail-on-regression` so a pipeline change can be proven to help or hurt, and `corpus/` is git-ignored because real songs and lyrics stay local. No runtime behavior changed.
- Files: `tool/asr_quality_report.dart` (new), `test/tool/asr_quality_report_test.dart` (new, 34 tests), `docs/asr_quality_baseline.md` (new usage and metric definitions), `.gitignore` (`/corpus/`), `docs/reviews/2026-10-31-recognition-quality-and-ux-deep-review.md` (Phase 0 status note), `docs/handoff.md`, `docs/log/entries/2026-11-01-1354-line-quality-baseline-tool.md`, and the regenerated `docs/work_log.md` / `docs/work_log_archive.md` / `docs/work_log_index.md`.

- Notes: The CLI smoke test caught two defects that the unit tests could not: an LRC file opening with `[ti:...]` was routed to the JSON parser because both start with `[`, and a `(?m)` inline flag is invalid in Dart's ECMAScript `RegExp`, which only surfaced when `dart run` executed the CLI. Both now have regression tests. Duplicate detection is deliberately time-gated: a fragment restating a line within 1500 ms counts, while a chorus repeating a minute later does not, and untimed input compares adjacent lines only so a text-only reference cannot inflate the metric. Aggregate timing metrics are weighted by matched pairs (exact for a mean and a tolerance rate); per-song medians and p95 are not recombined. No baseline number for real songs is claimed here: that requires the hand-checked corpus described in `docs/asr_quality_baseline.md`, which only the user can supply.
