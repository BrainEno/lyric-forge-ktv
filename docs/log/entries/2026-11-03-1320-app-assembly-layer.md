# [2026-11-03 13:20] Move the assembly layer into lib/app and inject the lyric editor

- Scope: Phase 4 item 4.2, first step. The app-wide singleton lived in `lib/core/services/` — the one layer every feature is allowed to import — so any screen could reach `ServiceLocatorGlobal.I` and no screen could be constructed without the whole service graph. This step moves assembly above the features (`lib/app/`), turns the singleton into a named `AppServices`, moves the routing table and the app widget with it, and migrates the lyric editor (plus the review inbox it is reached from) to constructor injection — including the forced-alignment runner that 4.1 had to leave behind in the screen.

- Notes: Three decisions are worth keeping. First, `Routes` stayed in `lib/core/navigation/routes.dart` while the table moved up: `app_destinations.dart` and every screen that pushes a route name live below `lib/app`, so putting the constants above them would have inverted the dependency and made `lib/core` import the assembly layer. Second, the forced-alignment runner is **not** nullable and has no default: the runtime question ("is `qwenRuntime` + `qwenAligner` actually ready?") can only be answered by settings storage plus runtime inspection, so an unavailable runtime throws the same two Chinese messages as before and the existing error path reports them — a nullable runner would have reintroduced a silent "no evidence" fallback in the widget. Third, `ReviewInboxScreen`'s optional repository became required rather than keeping the singleton fallback, since the router is now the only constructor and always has one. Behavior is otherwise unchanged: the service construction order in `AppServices.initialize` is byte-for-byte the same graph, and no screen's rendering or interaction code was touched. The remaining 34 files still call `AppServices.instance` on purpose — the ratchet only lets that number fall — and the next batch (player screen 7, `playback_lyrics_availability_sync` 5, `local_song_lyrics_import_action` 5) is where 4.2 continues.
