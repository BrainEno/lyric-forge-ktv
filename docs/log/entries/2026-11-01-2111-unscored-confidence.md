# [2026-11-01 21:11] Stop counting "no score" as "low score"

- Scope: Phase 3 item 3.3 of the recognition-quality roadmap (review R8), done before the deferred Whisper-parameter work because it needs no corpus and no device. Both engines had been writing a made-up number into every line: Qwen's native response usually carries no calibrated score, so `_lineConfidence` defaulted to 50, and whisper.cpp's `_segmentConfidence` did exactly the same when a segment had no token probabilities. Every consumer then compared that 50 against thresholds of 70 (editor review queue), 60 (hallucination candidates) and 75 (repetition analysis), so a fully correct Qwen draft arrived with "低置信度 42 / 待复核 42 / 智能复核 42" over the toolbar. The user could not tell "the model was unsure" from "we never asked", which is worse than showing nothing. Verification lives in one new unit-test file for the two scoring functions plus one test in each consumer that keeps the distinction fixed.
- Files: `lib/features/project/domain/models/lyric_document.dart` (new `LyricConfidenceSource`, `hasConfidenceScore`, `isLowConfidence(threshold)`, the shared placeholder constant, JSON round trip), `lib/features/transcription/domain/models/asr_confidence.dart` (new: pure scoring for both engines), `lib/features/transcription/data/services/qwen3_asr_native_transcription_service.dart`, `lib/features/transcription/data/services/whisper_cpp_transcription_service.dart`, `lib/features/transcription/data/services/high_quality_transcription_service.dart`, `lib/features/lyrics/domain/proofreading/asr_consensus_analyzer.dart`, `lib/features/lyrics/domain/proofreading/asr_repetition_analyzer.dart`, `lib/features/lyrics/domain/proofreading/asr_first_pipeline.dart`, `lib/features/lyrics/domain/proofreading/asr_hallucination_filter.dart`, `lib/features/lyrics/domain/services/lyric_review_priority_service.dart`, `lib/features/lyrics/presentation/screens/lyric_editor_screen.dart`, `test/features/transcription/asr_confidence_test.dart`, `test/features/lyrics/domain/proofreading/asr_first_pipeline_test.dart`, `test/features/lyrics/domain/proofreading/asr_consensus_analyzer_test.dart`, `test/features/lyrics/domain/services/lyric_review_priority_service_test.dart`, `docs/reviews/2026-10-31-recognition-quality-and-ux-deep-review.md`, `docs/log/entries/2026-11-01-2111-unscored-confidence.md`, `docs/handoff.md`, and the regenerated `docs/work_log.md` / `docs/work_log_archive.md`.
