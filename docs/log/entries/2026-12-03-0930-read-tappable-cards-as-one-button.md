# [2026-12-03 09:30] Read tappable cards and rows as one button

- Scope: The rest of A-04. Fourteen cards and rows outside the lyric editor were bare `InkWell`s, so a screen reader read their title, `·`-joined second line and badges as loose words, never said what a tap does, and left out state that was only a colour (a project's status dot, the playing song, an unavailable file). Buttons inside a card, such as the ⋯ menu, were separate stops named only 显示菜单. A shared `AppTapTarget` (`lib/core/widgets/app_tap_target.dart`, D-037) now reads each one as a single button: a sentence label, a hint for the tap, the disabled and current states, and the card's own buttons and menu entries as custom actions. Covered: the dashboard's queue preview, recently played and project cards; the two import cards; review inbox rows (全部标为已复核 becomes the row's action); the player's lyric list and three-line focus view (上一句/当前句/下一句); artist, album, mini album, playlist and song cards in the local library; playback queue rows (`container: false`, so the label joins the reorderable list's 上移/下移 node and the remove button stays a separate stop); the desktop background transcription bar (pause/resume as actions, progress as the value); and the phone's desktop-library track tiles and artist/album cards (download state in the label, download as the action).
