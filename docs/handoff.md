# Handoff

## 目标

第四十轮：用户说“先接着做下个功能”，实现 D-060——Windows 上自动分离的伴奏作为工程的 KTV 纯伴奏。

- 识别前分离出的 `accompaniment.wav` 在工程没有自己的伴奏时自动关联为伴奏轨（带 `AutomaticAccompaniment` 标记）；用户导入的伴奏不会被替换。
- 工程详情“伴奏与人声”新增“自动生成伴奏”（只分离、不识别），有进度和“停止生成”。
- 播放器对自动分离的伴奏默认从原曲开始，“进入 KTV”里可选纯伴奏。
