# Handoff

## 目标

第四十七轮：歌词校对 Ctrl+G 跳到指定行，跟随播放时可以自己翻看（D-067）。

- 跳到行：Ctrl/⌘+G 或“更多”菜单 →“跳到行”，输入行号或时间（`1:05`、`65s`），实时预览，跳转后选中并高亮，被筛选或搜索藏起的行会先显示出来。
- ↑/↓ 换行时列表跟着滚动。
- 跟随播放：手动滚动、方向键或跳行后暂停 5 秒；期间出现“回到正在播放的第 N 行”按钮；暂停的歌曲不会被拉回；就地编辑时不跟随。跟随和跳转都按实际行高定位。
