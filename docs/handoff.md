## 目标

审计路线的第二十四轮（第二十三轮 PR #495 已合并为 `4d4e3c4`）。用户要求“做加一键操作：对‘有人声没歌词’的地方直接重新识别，对误删的行一键恢复”，即第 23 轮报告建议的两个后续。要求有效代码量不少于 1000 行，PR 过 CI 后直接合并。

1. 一键识别空白段（D-045）：
   - `LyricVocalCheckActions` 规划识别范围（前后各多 0.3 秒，不进入相邻的行，不超出音频；短于 0.5 秒或长于 90 秒不发送），把识别结果裁到范围内作为新行插入，已有的行不变；
   - `LyricVocalGapDialog` 打开就自动识别，可切换 Qwen/Whisper、上一处/下一处（都会立即重新识别）、停止、再识别、试听，或标记“这里没有歌词”。
2. 一键恢复误删的行：按原来的时间放回，当作手动确认过的行；“全部恢复”不弹窗，“逐行查看”可勾选和试听。
3. 入口：识别摘要卡上每处空白段一个“识别 m:ss.s”按钮，有删除的行时显示“逐行查看”“全部恢复”；校对菜单“纠错”组也有这两项。记录新增 `restoredLines`、`dismissedSpans` 计数。
4. 文档：D-045、`high_quality_asr.md`、工作日志。
