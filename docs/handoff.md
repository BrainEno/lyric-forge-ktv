# Handoff

## 目标

审计路线的第三十轮（第二十九轮 PR #501 已合并为 `5830234`）：审视“歌词校对”的 22 个入口，并让用户用最少的操作得到最准确的歌词——联网时自动获取参考歌词再智能校对，不用自己找歌词粘贴（D-052）。

- 新增“一键校对”（菜单第一项 + 宽屏工具栏按钮）：按项目名、歌手、时长并行查询网易云音乐、酷狗音乐、LRCLIB，按与识别结果的逐行吻合度挑歌词，只应用安全批次，保留录音时间轴；再做默认文本清理、识别循环、（无歌词时）重复段落和时间轴修复，一步撤销。
- 没找到或对不上时可改歌名重找、粘贴歌词或只做本地整理；有拿不准的行时可直接用这份在线歌词逐行确认。

## 检查结果

- 手工试过三个接口（境外网络）：LRCLIB、网易云 `cloudsearch/pc` + `song/lyric`、酷狗 `krcs` + `download` 均可用；网易云 `search/get/web` 在境外返回加密结果，`search/pc` 要求绑定手机，已避开。
- 沙箱里没有 Dart/Flutter，格式、analyze 和测试都靠 PR 的 Flutter Quality Gate 和临时探针。
- 新增测试：查询解析、署名行清理、候选判定（覆盖率、时间平移/丢弃、繁简转换、同名不同歌）、并行搜索（去重、单源失败、超时）、一键校对用例（改错字保留时间、字幕删除、可信标记、漏行、手动编辑保护、溯源记录、无改动原样返回、时间轴修复）、三个来源的接口解析（假 HTTP）、菜单/工具栏入口。
