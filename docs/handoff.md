## 目标

第三十八轮（第三十七轮 PR #507 仍开着，同一分支继续）：按用户反馈修三处（D-059）。

- 暂停或队列放完时，律动条、唱片和暂停图标不再显示为“正在播放”；暂停时律动条变成三根一样低的淡色条。
- 音乐库“歌曲”页顶部重排：搜索框、一行同高（48dp）的工具栏（紫色“播放全部”、随机播放、排序、网格/列表、手机菜单）、更小的筛选标签、一行计数；手机上去掉重复的“音乐库”标题栏。
- 改歌曲信息后，关联的歌词工程一起改名，队列里两种条目都更新，歌词播放器和“正在播放”随之刷新。
