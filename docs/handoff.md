# Handoff

## 目标

审计路线的第十二轮（第十一轮 PR #483 已合并为 `7b0322a`）。用户这一轮只说“接着开发下一轮”，所以按第十一轮交接里的建议做：让自动配对的歌词看得出来、配错了能撤回（D-034），再收两个小尾巴。lib+test 代码量按以往要求不少于 800 行。

1. 自动配对的歌词可见、可撤回（D-034）：自动配对时在歌曲本地资料里记下 `lyricAutoLink`（文件、工程、配对依据、是否新建工程、版本号、配对前状态和阶段、歌词行指纹）。音乐库把这类歌标成“自动配对歌词”，有这类歌时出现“自动配对”智能列表；歌曲菜单里有“解除自动配对”，确认框写明文件名、配对依据和“文件本身不会删除”。解除时：歌词改过就不动并说明；工程是这次新建且之后没再保存就删掉；否则只去掉这份歌词并恢复配对前的状态。歌曲取消链接，队列里同一首歌改成无歌词，这个文件记进 `lyricAutoLinkDismissed`，以后不再配给这首歌。提示条可以撤销（按原依据重新导入）。手动导入或链接别的工程会清掉旧记录。
2. 小尾巴：播放列表和播放队列的拖动排序改用 `onReorderItem`（`onReorder` 在 Flutter 3.41 之后弃用，新回调已经替我们减掉了下移时的那一位）；校对收件箱的“待复核”徽标和参考歌词对齐的“待确认”改用警示色，与编辑器状态行一致（E-03）。
