# Handoff

## 目标

审计路线的第二十九轮（第二十八轮 PR #500 已合并为 `915fa83`）。用户截图指出 Windows 上左侧导航文字显示有问题：“音乐库”的“音”粗黑而“乐库”细灰，“校对”同样，要求修复。

1. 原因：应用没有指定字体，每个汉字单独走系统回退；繁体/日文系统上部分字落到微软正黑体或 Yu Gothic，只有简体才有的字落到微软雅黑。
2. 修复（D-050）：`AppTypography` 在系统回退之前先列出简体中文界面字体（Windows 首选 Microsoft YaHei UI），主题的文字主题和所有不合并文字主题的组件样式都使用它。
