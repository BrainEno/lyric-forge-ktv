# Handoff

## 目标

第四十三轮：用户发现有的歌有好几个歌词识别工程，而且没法删除。实现 D-063——工程可以删除，重复的工程一键清理，批量识别不再重复建工程。

- 首页“最近工程”→“全部工程”：搜索、删除、多选删除、自动找出重复工程并一键清理。
- 工程页“更多”→“删除工程”。删除前确认；可选同时删除工程文件夹；正在识别或播放的工程不能删。
- 批量识别遇到已有工程的歌：有歌词就跳过，没有歌词就用原工程识别。
