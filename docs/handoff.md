# Handoff

## 目标

审计路线的第三十二轮（第三十一轮 PR #503 已合并为 `136ed6c`）：没有时间轴的歌词（D-054）。

- 联网获取歌词：优先带时间轴的版本，保存前可以播放歌曲核对高亮是否跟得上、点行跳转试听、整体提前/推后 0.5 秒；对不上可以“只用文字（去掉时间戳）”。
- 粘贴歌词：纯文本直接保存为参考歌词；带时间的文本可选去掉时间戳。
- 播放器：无时间轴的歌词显示为“参考歌词（无时间轴）”，静态文本、手动滚动、无高亮、不自动滚动、点击不跳转；KTV 入口禁用，提供“去打轴”“联网找带时间轴的歌词”。
