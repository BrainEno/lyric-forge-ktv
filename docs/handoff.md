# Handoff

## 目标

第四十四轮：让操作界面更友好——误操作可撤回。实现 D-064：删除的工程先进“最近删除”（30 天内可恢复），常见的删除和移除操作都能一键撤销。

- 删除工程：单个直接删除并提供“撤销”；多选和一键清理仍先确认；“最近删除”页面可恢复、彻底删除、清空。
- 撤销：删除或移出播放列表、取消收藏、从音乐库移除和清理失效歌曲、播放队列移除和清空、删除歌词行。
- 演唱录音：删除后在列表原位置可撤销，8 秒后才删除文件。
