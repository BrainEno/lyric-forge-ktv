# Handoff

## 目标

审计路线的第二十六轮（第二十五轮 PR #497 已合并为 `8a855ce`）。用户要求：“把‘全部识别’做成整首识别流程的可选最后一步，让草稿一出来就已经补上漏句。”要求有效代码量不少于 1000 行，PR 过 CI 后直接合并。

1. 识别流程的最后一步（D-047）：
   - `TranscriptionConfig.vocalGapFill`，默认开启，设置里的开关“识别后自动补全漏句”；
   - `VocalGapFiller` 复用 D-046 的识别范围、换引擎规则和一次插入，每次最多 24 处、合计 4 分钟；
   - `LocalTranscriptionVocalGapFill` 从人声音轨裁剪片段、直接调用识别适配器，不另外申请租约，复用共享的 Qwen3-ASR；
   - `LocalProjectTranscriptionWorkflow` 在人声检查之后、保存之前运行这一步，进度显示在识别进度里，取消即取消整次识别，失败只记录不影响识别。
2. 自动补上的行进入复核队列（“识别时按人声自动补上的漏句，建议试听确认”），识别摘要卡显示“自动补句：n/m 行待听”。
3. 文档：D-047、`high_quality_asr.md`、工作日志。
